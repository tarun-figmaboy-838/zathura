# DRIFTBOUND: game plan

A retro-futuristic 3D space adventure in the browser. You're the crew of a lone
gunship lost in a strange nebula. Random "event cards" throw meteor storms,
raider attacks and gravity wells at you, and you fight back with a **360° dorsal
cannon turret**.

It's inspired by the *feel* of a space-adventure board game come to life:
tension, surprise events, a ship under siege. All names, ships, enemies and art
are original.

Target: **as close to AAA as a browser can get** using only **Three.js**
(rendering and game) and **headless Blender** (all 3D models, generated by
Python scripts, no hand modelling).

---

## 1. Pillars

| Pillar | What it means in practice |
|---|---|
| **Cinematic space** | HDR rendering, bloom, ACES tone mapping, nebula skybox that also lights and reflects on the ship, gas giant with atmosphere and rings, a sun with lens flare. |
| **Heavy, mechanical cannon** | The turret rotates a full 360°, has a limited traverse speed, recoils, alternates barrels, flashes the muzzle and shakes the camera. |
| **Readable chaos** | Events are announced, enemies telegraph attacks, and the HUD stays minimal. |
| **Procedural pipeline** | Every model comes from a Blender script, so the art can be changed and rebuilt with one command. |

## 2. Tech stack

- **Three.js r170** as ES modules through an import map (no build step and no Node needed).
- **Headless Blender 5.2** (`blender -b -P script.py`) builds and exports `.glb` models.
- **Python `http.server`** serves the game locally.
- Later, optionally: Vite, if we add npm packages (audio libraries, physics).

## 3. Controls

| Input | Action |
|---|---|
| Mouse (click the game to lock the pointer) | Orbit the camera 360° around the ship. The turret tracks the crosshair. |
| Left mouse (hold) | Fire the cannon (alternating barrels) |
| W / S | Thrust forward / reverse |
| A / D | Yaw left / right |
| R / F | Pitch nose up / down |
| Space / C | Climb / dive |
| Q / E | Roll |
| Shift | Boost |
| Mouse wheel | Camera zoom |
| Esc | Release the mouse |

## 4. Rendering recipe (the "near-AAA" checklist)

1. **HDR pipeline**: half-float render targets, 4× MSAA, ACES filmic tone mapping, sRGB output.
2. **Nebula skybox**: fbm-noise shader baked once into a cube map, then used as both
   `scene.background` and a PMREM **environment map**, so the metal hull reflects the nebula.
3. **Lighting**: a sun directional light with soft shadows that follow the ship, plus cool
   nebula fill from the environment map, a hemisphere rim light and emissive engines.
4. **Post-processing**: Unreal bloom, then a custom lens pass (vignette, chromatic aberration,
   film grain).
5. **Space depth cues**: three star layers, drifting space dust that streaks with speed,
   and atmospheric scattering on the planet.
6. **Juice**: muzzle flash lights, tracer bolts, sparks, debris, camera shake, FOV kick on boost.
7. **Materials**: bevelled hard-surface edges (they catch highlights), metal and roughness
   PBR, a triplanar panel and grime detail shader, emissive trim lights.

## 5. Asset pipeline (headless Blender)

```
blender/
  build_ship.py        → assets/models/ship.glb      (hull, wings, engines, turret rig)
  build_asteroids.py   → assets/models/asteroids.glb (8 rock variants with vertex color)
  build_raider.py      → assets/models/raider.glb    (enemy interceptor)
  build_station.py     → assets/models/station.glb   (station + round landing pad with animated clamps)
  build_all.sh         → runs everything
```

The turret rig is a named node hierarchy that the game looks up by name:

```
Ship
 └─ TurretMount        (fixed on the hull)
     └─ TurretYaw      (rotates 360° around the up axis)
         └─ TurretPitch (elevates -8°…+85°)
             ├─ Barrel_L ── Muzzle_L
             └─ Barrel_R ── Muzzle_R
EngineGlow_*            (emissive nozzle disks, driven by throttle)
NavLight_*              (blinking wingtip lights)
```

## 7. Performance budget (60 fps on an Apple-silicon Mac)

- Fewer than 150 draw calls (asteroids and projectiles are instanced)
- Fewer than 1.5 M triangles on screen
- One shadow-casting light, 2048² shadow map limited to the ship area
- Projectiles, sparks and explosions come from object pools (no allocations per frame)

## 8. Running it

```
python3 -m http.server 8123      # then open http://localhost:8123
./blender/build_all.sh           # rebuild ship.glb + asteroids.glb with headless Blender
```

In the browser console, `game.debug` has `look(yawDeg, pitchDeg)`, `fire(on)`, `key(code, on)`
and `advance(seconds)` for tuning and testing.
