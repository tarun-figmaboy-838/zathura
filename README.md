# Driftbound

A 3D space shooter that runs in the browser, built with Three.js and models generated by headless Blender.

Launch your gunship from the Haven-9 landing pad and fly five levels toward a black hole.
In each level you cruise, fight off raiders in a top-down battle with your 360° cannon, then
shoot your way through a meteor field. Level 5 ends with a boss, the Warden carrier, and then a
dive into the event horizon.

## Play

The game has to be served over http. Opening `index.html` directly won't load the 3D models.

- **Mac:** double-click `start.command`. The first time, macOS may block it: right-click it, choose
  **Open**, then **Open** again.
- **Windows:** double-click `start.bat` (needs Python from python.org).
- **Any system with Python 3:** open a terminal **in this folder** and run
  `python3 -m http.server 8123 --bind 127.0.0.1`, then open http://127.0.0.1:8123

Use a recent Chrome, Edge, Firefox or Safari. You need an internet connection the first time,
because the Three.js engine and fonts load from public CDNs.

## Controls

| Action | Mouse / touch | Keyboard | On-screen |
|---|---|---|---|
| Aim the cannon | point anywhere | – | – |
| Fire | hold click / touch | Space | Fire button |
| Steer (cruise and meteors) | – | Arrow keys or WASD | Left pad |
| Rotate the cannon (battles) | – | ← → | Orange rotate buttons |
| Lock-on: auto-aim for 5 s | – | E | Lock button |
| Shield: block all damage for 4 s | – | Q | Shield button |
| Pause / mute | – | Esc / M | Pause button |

The cannon overheats if you hold fire too long; the ring around the Fire button shows its heat.
When the boss's core is exposed, raise your Shield when the barrage warning appears.

## Project layout

```
index.html        page, HUD and on-screen controls
src/              game code (Three.js ES modules)
assets/models/    ship, raider, boss, station and asteroid models (.glb)
blender/          the Python scripts that generate every model
PLAN.md           design plan and milestones
```

## Rebuilding the models (optional)

Install Blender (the scripts were built and tested with Blender 5.2), then from this folder run:

```
BLENDER=/path/to/blender ./blender/build_all.sh
```
