# Driftbound

A 3D space shooter that runs in the browser, built with Three.js, with models generated by headless Blender
and the title and button art designed in Figma.

Launch your gunship from the Haven-9 pad and dive straight into a black hole. On the far side, fight
through five sectors: in each one you cruise through a sector gate, beat the raiders in an angle battle,
then shoot your way through a meteor field. Sector 5 ends with a boss, the Warden carrier, and then you
jump home.

## Angle battles

Each raider is a question. Lines are drawn through your ship: a dotted reference line (your cannon
rests on it), a red dashed line to the enemy, one marked angle and a **?** angle. Pick the value of
**?** and the cannon turns by that angle: the right answer lands on the enemy and destroys it; a wrong
one misses, the enemy fires back, and the narration box shows the rule (after a second miss, the working).
The enemy's ring drains while you think; when it empties, it fires.

| Sector | Rule |
|---|---|
| 1 | Opposite angles are equal |
| 2 | Angles on a straight line add up to 180° |
| 3 | The two parts of a right angle add up to 90° |
| 4–5 | All three mixed; in sector 5 the targets are the Warden's 4 turrets, then its core (3 hits) |

## Play

The game has to be served over http. Opening `index.html` directly won't load the 3D models.

- **Mac:** double-click `start.command`. The first time, macOS may block it: right-click it, choose
  **Open**, then **Open** again.
- **Windows:** double-click `start.bat` (needs Python from python.org).
- **Any system with Python 3:** run `python3 serve.py` in this folder, then open http://127.0.0.1:8123

`serve.py` tells the browser not to cache, so a normal reload always runs the latest code. With a
plain `python3 -m http.server`, reload with Cmd/Ctrl+Shift+R after changing files.

Use a recent Chrome, Edge, Firefox or Safari. You need an internet connection, because the Three.js engine
and fonts load from public CDNs.

## Deploy (Vercel)

It's a static site with no build step. `vercel.json` sets caching for the models, and `.vercelignore`
leaves out the Blender scripts and local launchers.

- **CLI:** run `vercel` in this folder (choose framework **Other**, no build command, output directory `.`).
- **Dashboard:** import the repository and set **Root Directory** to this folder, framework **Other**.

## Controls

| Action | Mouse / touch | Keyboard | On-screen |
|---|---|---|---|
| Answer a battle question | tap an answer | 1 – 4 | Answer buttons |
| Steer (cruise and meteor fields) | – | ← → or A D (W S to climb/dive) | Left / Right buttons |
| Aim the cannon (meteor fields) | point anywhere | – | – |
| Fire (meteor fields) | hold click / touch | Space | Fire button |
| Lock-on: auto-aim for 5 s | – | E | Lock button |
| Shield: block all damage for 4 s | – | Q | Shield button |
| Skip the intro | click | Space / Enter / Esc | Skip button |
| Pause / mute | – | Esc / M | Pause button |

In the meteor fields the radar ring around the ship shows where the cannon points and lights up while
you fire; the ring around the Fire button shows the cannon's heat.

## Project layout

```
index.html        page, HUD and on-screen controls
src/              game code (Three.js ES modules)
assets/models/    ship, raider, boss, station and asteroid models (.glb)
assets/ui/        title and button art (made with Figma AI, background removed)
blender/          the Python scripts that generate every model
PLAN.md           design plan and milestones
```

## Rebuilding the models (optional)

Install Blender (the scripts were built and tested with Blender 5.2), then from this folder run:

```
BLENDER=/path/to/blender ./blender/build_all.sh
```
